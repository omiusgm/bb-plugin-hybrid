---
name: hybrid
description: Настройки оформления плагина «Гибрид» и переключение его палитр.
---

`bb hybrid show` показывает настройки. `bb hybrid reset` возвращает обычную
плотность и включает цветокод, моноширинные мысли, рельсы, чипы,
выделение конечного ответа, приглушение завершённых ходов и цветные статусы.
Липкая полоса выключена: отдельный узел текущей работы в bb не найден.
«Марки авторов в ленте» (по умолчанию включено) показывает у реплик агента,
блоков «Message from», исходящих «Sent to» и строк про дочерние треды круглую
родную марку провайдера; выключение убирает только круги.
«Сворачивать прошлые ответы» по умолчанию выключено. При включении скрывает
только прошлые итоги, последний итог всегда раскрыт. Ручное раскрытие
сохраняется в памяти окна. Работу хода сворачивает ядро по настройке
провайдера; плагин не переключает родные блоки и не меняет completed-turns.
Речь агента имеет нейтральную линию, текущая реплика — подпись «Текущий ответ»,
итог завершённого хода — акцентную поверхность с подписью «Ответ».

Палитры: `bb theme set plugin:hybrid:grafit` (также terrakota, sosna, indigo,
pergament, nuar). Все шесть переключаются через Настройки → Внешний вид.
Переключатели оформления: Настройки → Гибрид. Смена действует сразу во всех
окнах bb. Весь структурный CSS ограничен `:root[data-hyb-active]`.
Чужая тема отключает оформление и удаляет декорации. Полностью отключить:
`bb plugin disable hybrid`. Не меняй тему без поручения владельца.
